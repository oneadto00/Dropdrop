package.json and their transitive closure in package-lock.json) plus frontend
runtime components bundled into dist/web. Purely development-time lint,
formatting, type-checking, and build-only toolchain packages that are not
distributed in Dropdrop releases are omitted.

Distribution notes:
- Include LICENSE, NOTICE and this file in npm tarballs and other distributions.
- Vue runtime code and minimal Vite asset helpers are included in the web
  bundle. Their MIT copyright and license notices are preserved both in the
  JavaScript delivered to browsers and in this file.

  preserved below. This does not relicense SQLite under Apache-2.0.

This is a package-level license and notice review. Review new versions and
release contents whenever runtime or bundled frontend dependencies change.

These are third-party declarations, not additional licenses for the original
Dropdrop code. Each component keeps its own license. Alternative license
expressions are reproduced as declared by upstream; for a permissive OR option,
an Apache-2.0 or MIT option may be used, while AND conditions remain cumulative.

by a content-derived identifier.
