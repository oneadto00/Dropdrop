# Dropbin

轻量级、私有化部署的局域网文件传输工具。

Dropbin 计划通过 npm CLI 在本地启动文件传输服务，让同一局域网中的电脑、手机和平板通过浏览器上传文件，并使用 **6 位随机数字取件码** 定位和下载文件。文件由部署主机暂存与传输，无需接入公共云存储。

> 项目状态：开发初始化阶段。以下为计划实现的产品能力，目前尚未发布可运行版本或 npm 安装包。

## 项目特点

- **本地部署**：通过 npm CLI 启动服务，提供局域网访问地址与二维码。
- **跨设备互传**：各设备访问同一网页，使用“上传”和“下载”两个入口完成传输。
- **凭码取件**：上传完成后生成 6 位随机数字取件码；验证成功后仅展示对应批次的文件，不提供公共文件广场。
- **大文件传输**：采用流式上传与下载，规划支持 HTTP Range 断点续传、进度统计和并发传输控制。
- **下载次数限制**：上传者设置最大下载次数，通过原子配额控制防止并发请求超额取件；有效会话的续传不重复计数。
- **自动销毁**：额度耗尽后停止新取件，已获准的传输结束或重试窗口到期后，清理该批次的暂存文件与相关业务记录；同时支持到期清理和主动撤销。
- **访问保护**：限制取件尝试频率，隔离上传存储路径，并控制临时文件、磁盘空间和传输资源的生命周期。

## 工作方式

1. 在局域网内的一台主机上启动 Dropbin 服务。
2. 发送者通过浏览器选择文件，设置下载次数与有效期，完成上传并取得取件码。
3. 接收者打开同一服务页面，点击“下载”，输入取件码后获取对应文件。
4. 服务根据下载额度、有效期或撤销操作清理对应传输数据。

部署主机需要在上传、取件和下载期间保持运行。文件先上传到主机，再由主机传输给接收设备；主机需要提供相应的可用磁盘空间。

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 运行时与语言 | Node.js、TypeScript |
| HTTP 服务 | Fastify |
| 浏览器界面 | Vue 3 |
| 元数据存储 | SQLite |
| 部署与分发 | npm CLI |

文件内容存储在主机的受控暂存目录中，SQLite 用于管理文件批次、取件授权、下载额度和生命周期状态。

## 使用边界

- 手机上传通过系统文件选择界面进行；下载保存位置受操作系统与浏览器能力限制，纯网页不保证所有设备均可在每次下载前选择目录。
- 6 位取件码用于文件定位与访问授权，不是加密密钥。普通 HTTP 不提供链路加密，应在可信局域网中使用。
- 自动销毁针对服务端暂存内容及相关业务记录，无法撤回接收者已经下载的副本，也不代表底层存储介质上的不可恢复擦除。
